# Module 01: ROS with Python, C++, and Rust

This directory covers the fundamentals of ROS (Robot Operating System) using three different programming languages: **Python**, **C++**, and **Rust**. 

The goal is to master core robotics communication patterns, understand how client libraries differ across languages, and build foundational nodes directly within this module.

---

## What I Will Learn

- **ROS Architecture & Fundamentals:** Understanding nodes, topics, publishers, subscribers, services, and the underlying computation graph.
- **Python Development:** Writing rapid-prototype nodes, handling standard callbacks, and using language-specific tools (`rclpy` / `rospy`).
- **Modern C++ Development:** Implementing object-oriented nodes, memory management, smart pointers, and high-performance communication pipelines (`rclcpp` / `roscpp`).
- **Rust Integration:** Exploring memory safety, concurrency models, and modern systems programming applied to robotics using Rust bindings.
- **Language Comparison & Trade-offs:** Evaluating execution speed, memory footprint, compile-time guarantees, and development speed across Python, C++, and Rust to choose the right tool for each robotic task.

---

## Structure

All notes, snippets, and exercise files for this module are kept directly in this folder for quick reference and lightweight experimentation.
